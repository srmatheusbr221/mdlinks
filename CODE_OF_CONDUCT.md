# Code of conduct

Be decent to each other. That's the whole idea.

In practice:

- Assume good faith, especially in issues written in a second language.
- Critique the code, not the person.
- No harassment, slurs, or personal attacks, in any language.
- Maintainers can edit, lock or remove comments that break these rules, and can
  block people who keep doing it.

If something goes wrong, open a private security advisory on this repo or
contact the maintainer through the email on the GitHub profile
([@srmatheusbr221](https://github.com/srmatheusbr221)).
